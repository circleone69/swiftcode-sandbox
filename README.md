# Buckzy sandbox (Swiftcode)

Live from GitHub Pages after you enable it:

1. Open https://github.com/circleone69/swiftcode-sandbox/settings/pages
2. Source: Deploy from a branch → `main` / `/` (root)
3. Save. Site will be https://circleone69.github.io/swiftcode-sandbox/
4. DNS: CNAME `sandbox` → `circleone69.github.io`

Do not upload these JS files to cPanel. Sanesecurity Foxhole will keep blocking them.
